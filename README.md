# Thyranix Internship – Task 4

## User Testing of Figma Prototype

### 📌 Project Overview

This project focuses on testing a Figma prototype with real users to understand how easily they can navigate and use the application.

The main objective of this task is to observe user interactions, identify usability issues, collect feedback, and improve the overall user experience.

---

## 🎯 Objectives

* Test the usability of the Figma prototype.
* Observe how users navigate through the application.
* Identify difficulties faced by users.
* Collect user feedback.
* Understand whether the design is easy to use.
* Identify areas that can be improved.
* Make design improvements based on user feedback.

## 👥 User Testing

User testing was conducted by asking users to interact with the Figma prototype and complete specific tasks.

### Testing Process

1. Introduced the prototype to the users.
2. Explained the basic objective of the application.
3. Asked users to perform different tasks using the prototype.
4. Observed how they navigated through the screens.
5. Recorded difficulties and confusion faced by users.
6. Collected their suggestions and feedback.
7. Analyzed the feedback.
8. Identified improvements for the prototype.

---

## 📝 Tasks Given to Users

The users were asked to perform tasks such as:

* Open the application.
* Navigate through the main screen.
* Explore the available features.
* Select the required option.
* Navigate between different screens.
* Complete the main user flow.
* Return to the previous screen when required.

The tasks were designed to check whether users could complete the main workflow without assistance.

---

## 📊 User Feedback

The following observations were collected during the user testing process:

| Area Tested   | User Observation                                         | Improvement                                |
| ------------- | -------------------------------------------------------- | ------------------------------------------ |
| Navigation    | Users were able to navigate through most screens easily. | Improve navigation clarity where required. |
| Buttons       | Some buttons needed clearer identification.              | Improve button labels and visibility.      |
| Screen Layout | The overall layout was easy to understand.               | Maintain a simple and consistent layout.   |
| User Flow     | The main flow was understandable.                        | Reduce unnecessary steps.                  |
| Content       | Users understood most of the information.                | Improve unclear text where required.       |

---

## 🔍 Key Findings

The user testing helped identify the following points:

* Users preferred a simple and clear navigation flow.
* Clearly labelled buttons made the prototype easier to understand.
* Consistent design elements improved usability.
* Some areas required better visual guidance.
* User feedback helped identify improvements that were not noticed during the initial design stage.

---

## 🛠️ Improvements Based on Feedback

Based on the feedback received from users, the following improvements were considered:

* Improved button visibility.
* Simplified navigation.
* Improved text clarity.
* Maintained consistent spacing and alignment.
* Improved the overall user flow.
* Made important actions easier to identify.
